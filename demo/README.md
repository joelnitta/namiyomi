# Synthetic demonstration

The four AB1 files and `Demo.json` were generated by `scripts/create_demo.py`.
They contain artificial sequences, Gaussian-shaped peaks, and illustrative
quality values. They do not represent biological samples or an instrument run.

To view the assembled example, use **File > Import Previous Project** and choose
`Demo.json`. To practise assembly from scratch, create a new project, import the
four AB1 files, select `Demo01_F` and `Demo01_R`, then choose **Build Contig
(manual)**. The two Demo02 reads form a separate contig. AUTO also works because
these names use one prefix per specimen/locus group.

The deliberate disagreement in Demo01 demonstrates a review flag. Its presence
is not a measured error rate or evidence of calibrated consensus quality.
