# Choosing a Sanger sequencing tool

[日本語](COMPARISON-ja.md) · [Back to namiyomi](../README.md)

namiyomi is intended for a specific job: inspect AB1 traces, assemble reads from one specimen and locus, review the consensus, and export a sequence. Its advantages are a focused interface, editable source evidence in the same workspace, and no application license fee or subscription. It does not replace every analysis available in a larger package.

The tables below compare documented capabilities, not speed or accuracy rankings. They were checked against primary project and vendor documentation on **4 November 2026**. Prices, packages, and supported operating systems can change. No head-to-head performance, accuracy, memory-use, or usability study has been conducted.

## Desktop applications

| Application | Assembly and chromatogram workflow | Automation and search | Platforms and setup | License / cost model |
| --- | --- | --- | --- | --- |
| **namiyomi 0.0.1** | Select two or more AB1 reads; inspect and edit the consensus above their aligned traces. Source edits recall the linked consensus. Return Reads to AB1 preserves source edits and cuts. | AUTO groups **unused** reads by the original filename before its first `_`, without rebuilding existing contigs. Inline Find checks both strands at 80–100% identity using ungapped, substitution-only matching. | Standalone Apple Silicon/macOS 15+ application and experimental Windows 10/11 x64 package. Dependencies are bundled. Windows hands-on PC testing is incomplete; macOS is not notarized. | Free; [MIT](../LICENSE.txt). No activation or recurring application fee. |
| **[ChromasPro](https://technelysium.com.au/wp/chromaspro/)** | Graphical overlap assembly, consensus generation, ambiguity highlighting, quality-based trimming, and aligned chromatogram editing. Its [history](https://technelysium.com.au/wp/chromaspro-version-history/) documents assembly of selected sequences. | Exact matching or optimal-alignment search, including consensus search. Filename-prefix grouping equivalent to namiyomi's AUTO was not established by the linked public feature/history pages; this is not a claim that it is absent. | The official page lists Windows compatibility. | Commercial: both subscription and perpetual licenses are offered on the [purchase page](https://technelysium.com.au/wp/purchase/). A trial is available. |
| **[Geneious Prime](https://www.geneious.com/tutorials/assembling-chromatograms)** | Sanger trimming, de novo/reference assembly, editable chromatograms and consensus, plus an extensive analysis environment. | The [assembly manual](https://manual.geneious.com/en/latest/AssemblyMapping.html) documents **Assemble by Name** with configurable delimiter and name part. [Workflows](https://www.geneious.com/tutorials/automated-workflows) can combine trimming, assembly, consensus extraction, and downstream analyses. | Windows, macOS, and Linux according to its [download page](https://www.geneious.com/updates). | Current [public plans](https://www.geneious.com/pricing) are paid annual subscriptions; a trial is available. | **[SeqTrace](https://github.com/stuckyb/seqtrace)** | A focused GUI for trace inspection/editing and consensus generation from matching forward/reverse traces, with trimming and FASTA output. | **[UGENE](https://ugene.net/)** | A broad bioinformatics desktop environment with a [Sanger Reads Editor](https://ugene.net/docs/sanger-reads-editor/) and [CAP3 integration](https://ugene.net/docs/extensions/cap3/) for small-scale assembly. | Offers multiple analysis tools and workflow facilities rather than a single AB1-to-consensus interface. CAP3 assembly and the chromatogram editor are distinct documented components; do not assume every assembly opens in the same trace view. | Windows, macOS, and Linux. | Free/open source; the repository includes a [GPL-2.0 license](https://github.com/ugeneunipro/ugene/blob/master/LICENSE.txt). |

Geneious licensing deserves a qualification: its current pricing page advertises annual plans, but its support documentation also discusses [legacy Prime 2019 perpetual licenses](https://help.geneious.com/hc/en-us/articles/360045072611-What-is-Geneious-Prime). It would therefore be inaccurate to say that every Geneious user must pay annually. Likewise, ChromasPro should not be described as subscription-only.

## Related tools on GitHub

These projects solve overlapping problems, but they are not interchangeable desktop editors.

| Project | Interface and documented scope | Where it differs from namiyomi | Availability / licensing |
| --- | --- | --- | --- |
| **[sangeranalyseR](https://github.com/roblanf/sangeranalyseR)** | R/Bioconductor package with local Shiny interfaces, automated contig processing, interactive trimming, chromatogram visualization, FASTA output, and HTML reports. | Suits reproducible R workflows. Its [tutorial](https://sangeranalyser.readthedocs.io/en/latest/) explicitly distinguishes interactive exploration from manual base editing and states that hand editing should be performed in another tool. namiyomi provides direct base editing without requiring an R session. | Free/open source; requires R and its dependencies. The current README labels GPL-2, while the repository LICENSE file contains MIT text; inspect the files in the particular release rather than inferring terms from the GitHub badge alone. |
| **[Tracy](https://github.com/gear-genomics/tracy)** | A **command-line** tool for basecalling, alignment, assembly, deconvolution, and variant-oriented outputs. Companion web applications support result exploration. | Useful for scripted pipelines and analyses outside namiyomi's scope. It is not a standalone, project-based desktop chromatogram editor. | Free/open source, BSD-3-Clause. [Official documentation](https://www.gear-genomics.com/docs/tracy/) describes command-line installation and separate web applications. |

Upstream documentation and repository activity are not substitutes for testing a particular release on a particular computer. This comparison does not label a project unsupported or abandoned based on the date of a README or release announcement.

## Where namiyomi is a good fit

| Practical requirement | What namiyomi provides | Boundary to keep in mind |
| --- | --- | --- |
| No recurring license cost | The complete application workflow and source code are available under MIT, without paid activation. | Other free/open-source choices also exist. Commercial alternatives can provide broader capabilities and support. |
| Review a contig while looking at its evidence | The consensus, aligned source traces, quality bars, and review flags stay in one workspace. Source edits update the consensus and can be undone. | This is not a unique capability; ChromasPro and Geneious also provide chromatogram/contig editing. |
| Assemble selected reads without trusting filenames | Manual assembly accepts two or more selected reads and checks both orientations. AB1 import alone never groups or assembles reads. | The user must still select the same specimen and locus. Greedy overlap assembly cannot resolve every repeat or detect contamination reliably. |
| Batch simple, consistently named samples | AUTO uses the first filename prefix and protects reads already assigned to existing contigs. | The rule is deliberately narrow. Geneious and R tools offer more flexible naming/workflow configuration. |
| Find a motif during review | Find sits above the consensus, highlights both-strand matches, and allows an identity threshold of 80–100%. | This is an interface choice, not a measured speed advantage. Search is ungapped and treats IUPAC symbols literally, unlike wildcard-aware or optimal-alignment searches. |
| Use a focused application on a Mac | An Apple Silicon application is supplied with its runtime, without requiring a separate analysis environment. | macOS 15+ only; no Intel/universal or Linux package. Windows is experimental. The Mac package lacks Developer ID signing/notarization; Windows lacks Authenticode signing. |

The interface favors a narrow review workflow; whether it feels easier to use is a matter for users to judge. Claims such as “faster search,” “more accurate assembly,” “lower memory use,” or “better than Geneious/ChromasPro” require a defined dataset, matched settings, measured results, and reproducible methods. No such benchmark is claimed for version 0.0.1.
